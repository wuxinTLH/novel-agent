# 管理控制台

中文 | [English](README_en.md)

`Administration.tsx` 通过现有本机管理令牌或具有显式权限的已认证会话访问管理 API，不改变认证启动模式。超级管理员、管理员与运维管理员按共享权限表显示不同入口；作家不开放管理中心。默认展示工作台；桌面侧栏、窄屏横向分类导航共用 tab / tabpanel 关联，支持方向键与 Home / End。

## 日常操作

- 工作台：只读状态和快捷入口，不把已加载租户数量描述为在线人数。
- 用户、数据库、系统与安全：保留现有服务端鉴权、操作确认、保存状态及离开保护。
- `OnlineMaintenance.tsx`：创建全应用备份 → 选择成功备份并校验 → 按权限生成离线恢复计划；运维仅可备份及校验，不可取消任务或生成恢复计划。详细安全边界和 CLI 命令使用原生 details 分层，不移除停服要求。
- 成功备份从最近任务选择；旧备份可在高级输入填写 UUID，前端格式检查不代替服务端受管目录及完整性校验。任务提交超时不自动重试，提交阶段不能取消。

## 安全边界

认证继续默认关闭；首次管理员仍需离线 CLI 引导。在线备份必须确认全部租户短暂停顿和敏感材料，不开放任意路径或备份下载。校验仅证明完整性，计划绝不执行恢复；恢复与迁移必须停服。服务端权限、CSRF、全局静默屏障以及任务管理实现保持不变。

## 验证

在仓库根目录运行 `npm run build`、`npm test`；构建后运行 `node scripts/smoke-administration-ui.mjs` 验收隔离数据目录中的管理导航、备份、校验、计划和响应式布局，不访问真实用户数据。
