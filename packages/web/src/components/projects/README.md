# Projects library and account toolbar

- The sidebar **全部作品** entry and the breadcrumb open the dedicated `/projects` route. The current work remains selected until a card is opened; selection respects the unsaved chapter warning and running/busy safeguards.
- The library displays only the current user's `/api/projects` results, with cover/placeholder, chapter count, update time, searchable title/type/description, genre filter and sorting. **打开作品** continues the workflow; **设置** opens that project's settings; **新建作品** retains the existing form. **删除** passes the card id through required `onDelete(id)`; confirmation and mutation stay in the parent. Deleting a noncurrent card must not first activate it or change the current selection. Deleting the current card selects a surviving project through the existing parent flow. Delete is disabled while the library is disabled or only one project remains; the last-project tooltip explains why.
- `useLocale` supplies the library's current locale. Component-scoped Chinese/English copy covers its visible labels, accessible action names, placeholders, metadata and empty states; dates and title collation use that locale. User-supplied titles, genres and descriptions are never translated. The scoped copy intentionally avoids adding keys to the shared typed dictionary. Card actions use two rows (full-width Open, then Settings/Delete) to fit narrow cards and English labels.
- Mode/account status sits below the sidebar logo; the administration entry is below the guide and remains permission-gated (local administrator availability or authenticated admin permission). Language is left of the theme menu in the top bar. Native local authentication still defaults off; server requires it enabled offline.
- `WorldStagePanel` organizes worldbuilding references, including text/uploads/map images, into named stages or Ungrouped. Legacy assets remain ungrouped; only empty stages can be deleted. Stage filtering is library presentation, not generation-reference filtering: empty node selection still means all assets. Moving an asset uses its expected revision.
- Novel/character/worldbuilding creation buttons and dialogs use the current workflow family and preserve its selected active workflow; no silent family conversion is implied.

For isolated UI acceptance, after the parent has wired `onDelete(id)`, run `npm run build && node scripts/smoke-projects-library.mjs`. The script copies built server/web artifacts into a temporary app root, symlinks dependencies, scrubs inherited application environment, and creates only temporary local data; it never loads the repository's `.env` or real data. It covers parent-integrated cancel/confirm deletion of noncurrent/current fixtures, selection preservation/fallback, the final-project guard, English library UI with untranslated user titles, and responsive widths. Viewport screenshots are saved under ignored `.tmp-build/projects-ui`. Browser smoke requires a fresh parent build; syntax/unit checks alone do not establish integration acceptance.
