# Models

Model provider integration and model configuration routes live here.

Runtime fields are defined in `shared/model-runtime.ts`. Optional fields preserve old stored profiles; defaults are temperature 0.8, maxOutputTokens 6000, timeoutMs 180000, contextWindow 128000, vision true, maxImages 4. Responses/Anthropic omit temperature unless explicitly configured, preserving their previous request shape. Prices are per one million tokens in one user-selected currency; missing prices mean unknown, zero means free.

POST/PATCH `/api/models` and PUT `/api/settings` accept runtime fields and reject non-finite values, invalid ranges and output > context windows before mutation. PATCH/PUT also accept `clearInputPrice` / `clearOutputPrice`. POST `/api/models/:modelId/preflight` accepts `{ text?, imageCount? }`, checks configured capabilities without a provider request and returns a clearly estimated input token count. The transport runs the same preflight on the actual context and images before fetching.

Generation integration uses `generateModelTransport(settings, context, images, signal, { buildRequest: buildProtocolRequest, parseResponse: parseProtocolResponse, assertUrl: assertResolvedPublicModelUrl, onUsage? })` from `generation/model-transport.ts`. Dependencies are injected to avoid a circular import. Return `result.text`; persist or emit `result.usage` via onUsage only after successful complete output. The transport requests SSE but accepts bounded JSON fallback, refuses truncation/refusals/incomplete streams, caps raw response bytes at 8 MiB, disables redirects, cancels readers and uses one abort/timeout signal through request + body consumption. Provider text and credentials are never included in transport errors. It does not persist partial streamed output; onText is suitable for transient preview only.

Optional per-call budgets default to disabled: perCallBudgetTokens is an integer 1–10000000; maxEstimatedCostPerCall is 0–1000000 in the same currency as prices. Preflight reserves estimated input plus configured max output tokens, and the corresponding input/output cost. A configured cost budget requires both prices; zero is valid for free providers. Exceeding either budget rejects before DNS/request construction/network. Fees remain estimates, not a guaranteed provider bill ceiling. PATCH/PUT clearTokenBudget / clearCostBudget disable budgets. Clearing a price while keeping a cost budget is rejected before mutation.

Usage has inputTokens, outputTokens, totalTokens, estimated, optional estimatedCost. Exact provider usage wins; missing counts use a conservative code-point approximation and mark estimated=true. Prices must both be configured to compute a cost. Context/image estimates are not a model tokenizer; image input budgets use 4096 tokens/image.

`ModelSettingsPanel.tsx` directly connects its form to existing CRUD endpoints. Shared ModelProfile and ModelSettings should extend ModelRuntimeOptions. The generation owner must run transport on the real generate() path, pass all selected images before preflight (do not silently slice them), and retain bounded usage records; App does not need additional model form wiring.
