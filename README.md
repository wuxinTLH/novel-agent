# Novel Agent

本机单用户小说创作工作台：多作品、多工作流、资料上传、指定章节与区间创作、正文要求、候选稿对比、版本保护、人工编辑和 Markdown 导出。保留现有 Responses API、Chat Completions、Anthropic Messages 三种模型协议。

> **交付状态：本地创作功能与生产构建已实现；番茄真实账号接入尚未完成。**
> 旧版把番茄当作本地 Mock 的行为已移除。当前具备独立登录窗口和经过离线测试的草稿任务、加密会话、去重与回执框架，但真实作者身份、作品列表、草稿编辑器及回读定位仍待实现和实测。生产适配器明确返回 `needs_verification`，不会伪造账号连接或草稿保存成功。**安装浏览器或切换配置不能解除这个实现缺口。**

## Windows 本地启动

需要 Node.js 22.16+ 和 npm；本次构建及浏览器检查使用 Node.js 24。

在项目目录运行：

```powershell
npm ci
npm run build
npm start
```

在浏览器打开 `http://127.0.0.1:3001`。生产构建生成前端 `dist/` 和后端 `build/`；`npm start` 运行编译后的 Node 服务，不依赖 `tsx`。构建需要开发依赖，不能先 `npm ci --omit=dev` 再构建。

开发模式：

```powershell
npm run dev
```

开发界面为 `http://127.0.0.1:5173`，API 为 3001，均只监听本机。修改 API 端口时，同时调整 `vite.config.ts` 的代理配置。不要将端口转发到公网。

可选的浏览器依赖安装：

```powershell
npm run browser:install
```

这会下载 Playwright Chromium，不会登录账号或上传正文。浏览器只在用户明确发起登录操作时启动。下载失败不影响本地写作；若安装提示锁文件，先确认是否还有安装进程，不要在下载进行时删除锁。

## 指定章节与正文要求

1. 在「模型设置」配置现有模型服务；无密钥时使用演示模式。演示模式仅输出模板，不保证满足剧情或风格要求。
2. 在「章节书稿」点击 **生成章节 / 要求**，或从工作流运行按钮、开始节点进入同一配置窗口。
3. 选择 **续写新章 / 指定单章 / 指定区间**，填写章号。区间为包含首尾的闭区间，单批最多 100 章，章号最大 1,000,000。
4. 设置作品级要求或某一章的专属要求。专属要求可以预先保存给尚未生成的章节，不会创建空白占位稿。
5. 检查本次目标与合并要求后开始。要求未保存时可选择「只保存要求」或「保存要求并开始」。

### 章号和原稿保护

- 章号是独立持久字段，不是列表下标，也不从标题推断。章节删除后，其他章节不重新编号。
- 默认续写使用历史章号高水位。完整运行启动时会预留该批全部章号，即使部分失败或取消，默认续写也不会复用这些号码；可显式指定单章或区间补齐空缺。
- 新建模式遇到已有章号会在调用模型前拒绝，不静默覆盖或跳过。
- 已有章节选择 **重生成此章** 后，只生成候选稿。原稿保持不变；「对比原稿」后显式「采用新稿」才替换，保留章节 ID 和原稿修订记录。
- 采用时检查原稿版本。原稿被编辑、删除或候选不符合硬性要求时拒绝采用；放弃候选不会改变原稿。
- 一个目标只保存一个最终正文。如果有多个正文节点，必须指定最终输出节点；其他节点只产生中间结果。
- 区间按章号顺序执行，后续失败不会删除已完成章节。停止不会撤销已经保存的本地章节。

### 额外内容如何生效

| 输入           | 处理方式                                                                                 |
| -------------- | ---------------------------------------------------------------------------------------- |
| 创作要求       | 自然语言描述剧情、人物、视角、风格、必须发生或禁止揭示的内容；传入规划、正文与审校上下文 |
| 必须原文出现   | 对最终章节内容逐字检查，区分大小写，保留输入中的空格及换行                               |
| 禁止出现的原文 | 对最终章节内容逐字检查；出现即不合格                                                     |

作品级与单章要求累加，界面可查看合并结果。硬性文本互相矛盾时拒绝运行；字段可明确清空，不会因空值被省略而保留旧要求。

生成时保存有效要求快照；只自动引用目标章之前最近三章，不把后面的章节当作前文。重生成原稿放在独立上下文块。正文被要求将创作要求融入故事，而不是仅输出要求清单。

**硬性文本检查失败不会提交为合格正文**，失败输出可保留为待检查候选。语义和文学质量由模型审校提供建议、最终由作者确认：这不是语义百分之百符合的机器保证，也不包含自动无限重写。模型返回空正文、截断或失败状态时不会作为成功章节提交。

## 工作流与编辑行为

- 开始和结束节点固定保留，只允许调整位置，不能转换成普通模型节点。
- 节点按依赖拓扑顺序执行，合流等待前驱；循环、不可执行连接和禁用依赖会明确报错。
- 单节点运行只更新该节点输出，不自动增加章节；依赖结果必须属于同一目标、要求和图版本。需要生成书稿时运行完整工作流。
- 撤销只恢复当前工作流的配置与图结构，不回滚章节、平台信息或旧运行结果；图版本过期会拒绝覆盖。
- 正文保存采用章节版本校验；保存期间继续输入、切章或切换工作流不会让旧响应覆盖新稿。出现冲突时可先导出当前输入，再载入服务器版本。
- 节点模型可显式选择「跟随全局」。全局演示/真实模式决定是否调用模型，不会因为某个模型配置保存为真实模式而意外产生调用。

## 番茄平台：当前边界与待完成验收

本工具不是番茄官方客户端，也不声称使用已经获批的官方作者 API。

| 能力                                           | 当前状态                                           |
| ---------------------------------------------- | -------------------------------------------------- |
| 旧番茄本地模拟与真实账号隔离                   | 已实现，旧记录备份并归档                           |
| 独立可见浏览器、人工登录入口                   | 已实现；需要浏览器安装和本机桌面，尚未真实账号验收 |
| 真实作者身份识别、作品读取                     | **未实现实际页面适配，生产关闭**                   |
| 真实草稿编辑、回读验证                         | **未实现实际页面适配，生产关闭**                   |
| 草稿预览、批准、任务、去重、未知结果处理、回执 | 已实现协议与离线假适配器测试，不代表线上可用       |
| 正式发布、自动上传、远端删除                   | 不提供；旧发布接口返回 410                         |
| 起点、七猫                                     | 尚未接入                                           |
| Mock                                           | 仅限明确标记的本地演示；不要输入真实平台凭据       |

需要后续完成 `server/fanqie-browser.ts` 的身份验证、作品读取、草稿创建、精确回读和查找方法。目前这些方法有意拒绝操作，不可仅修改 readiness 开关。

### 真实适配完成后的操作契约

1. 用户在隔离窗口自行登录，验证作者稳定 ID；验证码和密码均由用户输入，不提取或代填。
2. 明确选择一个账号和作品，不默认选第一条绑定。
3. 在书稿页保存章节，再点「同步此章到草稿」；该入口本身不会上传。
4. 预览完整标题、正文、目标作品和内容版本，明确批准后才允许首次远端写入。新建草稿或填写编辑器也视为写入，不能假定点击保存前不会自动存稿。
5. 写入前持久化任务意图，保存后重新打开精确草稿核对标题、正文和段落，成功后持久化独立回执，不写“已发布”。
6. 相同账号/作品/章节版本/内容哈希重复请求返回已有结果。可能已写入后的超时或崩溃标为 `unknown`；只读核对，禁止盲目重发。不同正文版本的安全远端更新尚未开放，不会自动另建重复稿。

正式接入完成必须经过用户参与的 **真实登录 → 作品核对 → 批准指定一章 → 保存草稿 → 页面回读 → 重试不重复 → 重启复查**。验收不点击正式发布，也不自动删除远端验收稿。

### 凭据与本地安全

- 平台会话默认仅在内存。设置强随机 `PLATFORM_SECRETS_KEY` 才持久加密保存；重启恢复仍需实际网站验证，不保证所有登录方式都可恢复。
- 不落明文认证状态、不复用个人浏览器配置、不记录 Cookie/密码、不默认记录登录截图、trace 或 HAR。错误密钥和损坏数据不会覆盖原文件。
- 全部本地 API 修改请求检查 `X-Platform-CSRF`；Host、Origin 和跨站请求也受限制。`GET /api/platforms/session` 提供当前进程的 CSRF 和功能状态。凭据或平台存储降级不阻止获取本地写作所需 token。
- CSRF 不是用户身份认证；不防御同机恶意进程、恶意扩展或 XSS，不适用于公网和多人部署。
- 同一数据目录只允许一个服务实例。项目生成与平台任务互斥；同一作者的草稿操作串行。
- 解绑、断开及删除项目只清理本地数据，不删除远端作品。

## 模型配置与数据

复制 `.env.example` 到 `.env` 后编辑；不要覆盖已有 `.env`：

```dotenv
PORT=3001
MODEL_BASE_URL=https://api.openai.com/v1
MODEL_NAME=gpt-4.1-mini
MODEL_PROTOCOL=chat-completions
MODEL_API_KEY=your-api-key
# DATA_DIR=E:/novel-data
# PLATFORM_SECRETS_KEY=your-stable-random-secret
```

`MODEL_PROTOCOL` 可选 `responses`、`chat-completions`、`anthropic-messages`。模型配置保存在 `models.json`，密钥存入独立加密文件，不回传到浏览器或写入小说项目 JSON。模型密钥可使用 `MODEL_SECRETS_KEY`，否则使用本地 `model-secrets.key`；备份应同时考虑数据可恢复性和密钥安全。模型选择及执行模式仍有进程级状态，重启后请核对设置。

真实模式会把选定设定、同目标上游结果、目标之前最近三章及创作要求发送给配置的模型服务。每节点超时 180 秒，文本上下文上限 150,000 字符，响应上限 6,000 tokens；超限报错，不静默截断输入。

- 文本支持 UTF-8 `.txt`、`.md`、`.json`，单文件最多 2 MiB。
- 图片支持 `.png`、`.jpg`、`.jpeg`、`.webp`，单文件最多 4 MiB；使用当前节点选定资料中的前四张，模型须支持图片。
- 每批最多上传 10 个文件，每作品最多 100 份资料。PDF、DOCX、OCR 未提供。
- `DATA_DIR` 默认是应用根目录下 `data/`，相对路径也以应用根目录解析，不受启动工作目录影响。
- `projects.json` 存小说、要求、章号、修订、候选及运行数据；`uploads/` 存图片；平台文件独立保存。
- JSON 写入使用临时文件替换。章节/图修改有版本保护，但不是多进程数据库；不要同时运行多个版本访问相同目录。

### 升级、备份与恢复

1. 正常停止程序后备份整个 DATA_DIR，并安全保管 `.env` 及加密密钥；不要把密钥和公开备份放在一起。
2. 首次升级为旧项目补稳定章号和版本，保留章节 ID/正文；备份为 `projects.pre-generation-v1.json.bak`。旧番茄平台 v1 文件保留为 `platform-connections.json.v1.bak` 并隔离模拟记录。
3. 全部工作流旧 `autoPublish` 禁用；旧本地“已发布”只归档为 `legacyPublishedAt`，不代表真实发布。
4. 中断的生成标为失败；可能已写入的草稿任务转为未知，不自动恢复上传。
5. 恢复前停止服务并备份当前状态；恢复完整、相互一致的数据和对应密钥，不混合不同时间的项目/平台文件。
6. `.instance.lock` 防止同目录多实例。启动时只会自动回收已确认原进程不存在的旧锁；原进程存活、权限不足或锁内容不完整时仍会拒绝启动，不自动删除。锁恢复也互斥进行，避免多个实例同时抢占；若提示 `.instance.lock.recovery` 遗留，先确认没有启动/恢复进程再人工处理，不能绕过仍在运行的实例。

## 验证

```powershell
npm run typecheck
npm test
npm run build
npm run smoke
```

`npm test` 使用临时目录、本机模型 stub 和假平台适配器，无真实模型费用或账号操作。`npm run smoke` 启动临时 DATA_DIR 下的生产服务并通过独立浏览器检查界面，不使用真实小说数据；截图保存至忽略提交的 `test-results/production-smoke/`。

默认 smoke 使用安装的 Chromium。Windows 已有 Edge 时可显式选择独立 Edge 会话：

```powershell
$env:SMOKE_BROWSER_CHANNEL = 'msedge'
npm run smoke
Remove-Item Env:SMOKE_BROWSER_CHANNEL
```

本地浏览器 smoke 验证指定第 5 章、要求保存、正文编辑、原稿保护、候选采用、刷新恢复和平台未验收提示；这不等于真实模型质量或真实番茄同步验收。

## 主要接口与代码

所有路径均以 `/api` 开头。修改请求需要当前 `X-Platform-CSRF`，前端客户端统一处理；不得自动重试有副作用的请求。

| 方法                 | 路径                                                            | 用途                                              |
| -------------------- | --------------------------------------------------------------- | ------------------------------------------------- |
| GET / POST           | `/projects`                                                     | 列表、新建作品                                    |
| GET / PATCH / DELETE | `/projects/:id`                                                 | 读取、编辑、删除作品                              |
| PUT                  | `/projects/:id/graph`                                           | 按 workflowId 与 expectedGraphRevision 恢复配置图 |
| PUT                  | `/projects/:id/workflow`                                        | 可编辑工作流设置，不接受边界或 autoPublish        |
| POST / DELETE        | `/projects/:id/nodes`                                           | 新增或批量删除普通节点                            |
| PUT                  | `/projects/:id/edges`                                           | 编辑连线                                          |
| PUT                  | `/projects/:id/requirements`                                    | 保存作品级和按章号要求                            |
| POST                 | `/projects/:id/run`                                             | 指定工作流、目标、模式和最终正文节点，返回 202    |
| POST                 | `/projects/:id/cancel`                                          | 停止运行                                          |
| PATCH / DELETE       | `/projects/:id/chapters/:chapterId`                             | 需要 expectedRevision 的正文修改/删除             |
| POST                 | `/projects/:id/candidates/:candidateId/accept`                  | 检查原稿版本后采用候选                            |
| DELETE               | `/projects/:id/candidates/:candidateId`                         | 放弃候选                                          |
| GET                  | `/platforms/providers`、`/platforms/session`                    | 真实能力、降级原因及本地会话                      |
| POST                 | `/projects/:id/platform-connections/tomato/login/start`         | 显式打开登录窗口                                  |
| GET / POST / DELETE  | `/projects/:id/platform-login/:loginId`（完成为 `/complete`）   | 查询、完成或取消登录                              |
| POST                 | `/projects/:id/platform-drafts/prepare`                         | 生成指定绑定和单章内容预览                        |
| POST                 | `/projects/:id/platform-drafts/execute`                         | approved、内容哈希及幂等键校验后执行              |
| GET                  | `/projects/:id/platform-operations`、`/platform-draft-receipts` | 本地任务和独立回执                                |
| POST                 | `/projects/:id/platform-operations/:operationId/reconcile`      | 对未知结果只读核对                                |
