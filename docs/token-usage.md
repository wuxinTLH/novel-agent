# Token 使用统计与审阅工作台

## 管理入口与权限

管理控制台新增「Token 使用统计」。认证模式仅 `admin` 与 `superadmin` 具备 `usage.read`，运维管理员与作家不能读取接口；角色权重不是授权规则。认证关闭时仍沿用严格回环本机管理授权，不开放远端匿名统计。数据是跨租户的模型调用汇总运维元数据，不授予管理员读取租户正文或密钥的能力。

`GET /api/admin/token-usage?from=YYYY-MM-DD&to=YYYY-MM-DD&model=...` 使用 UTC 自然日，含首尾日，最小 1 天、最大 31 天。`model` 可省略，传入时按模型名称精确筛选。前后端均验证日期，不接受自动归一化的不存在日期。响应契约见 [shared/token-usage.ts](../shared/token-usage.ts)。

## 时间显示

前端实际时间戳统一固定转换为 UTC+8，显示格式 `yyyy:mm:dd HH:mm`，不显示时区后缀。例如 `2026-11-07T05:03:04.206Z` 显示为 `2026:11:07 13:03`，不随浏览器语言或系统时区改变。仅转换显示，不修改持久化时间。统计日期筛选、每日桶与速率分母仍按 UTC 自然日计算；日期桶仅显示 `yyyy:mm:dd`，不把每日聚合误当成某个具体时刻。

## 指标口径

- 输入、输出、总 Token；请求数；成功、失败及待定数；估算请求数。
- 平均 RPM = 请求数 / 所选完整日期的全部分钟；平均 TokenPM = 总 Token / 同一分钟数。它们不是仅活跃分钟的均值，也不是模型限流额度。
- 峰值 RPM / TokenPM 使用实际 UTC 分钟桶聚合，不能从每日总量反推。
- 供应商返回的用量与估算量区分。缺少供应商数据不等于零费用，估算不是供应商账单，不用于财务结算。
- 采集从更新后的调用开始，不回填未记录的历史；覆盖状态明确不保证完整。当前保留窗口为 31 个 UTC 自然日。
- 请求在联网前登记；进程中断可能留下待定登记，不能据此证明供应商已收到或完成请求。统计写入失败不能成为自动重发已完成模型请求的理由。

Three.js 饼图显示模型 Token 占比，柱状图显示按日 Token 用量；同时提供可键盘访问的数据表。图形按需加载，并在关闭统计页时释放 GPU 资源。WebGL 不可用时保留数据表，不影响查看统计。筛选响应在组件卸载后不得回写旧界面。

## 存储与隐私

统计为独立控制面运维元数据，并非租户业务存储的 SQL 失败回退。租户 Worker 通过私有通道向控制面提交经过校验的计数，不接受客户端自报 owner、存储路径或其他租户内容。不保存提示词、生成正文、API Key、端点 URL、用户/作品/运行标识。模型名称属于统计维度，仍应避免将秘密写入模型名称。

具体持久化、保留、容量、未完成登记和故障语义见 [管理模块说明](../packages/server/src/features/administration/README.md)。完整应用备份包含该控制面本地文件；它不是租户 SQL 快照文档。在线备份必须使用全部写入者静默屏障，恢复或迁移须停止全部运行时；不要把统计文件当作普通静态资源开放下载。

当前实现使用有上限的同步原子整文件写入，可能占用控制面事件循环；容量为 150,000 个分钟/模型桶、100,000 个保留期内请求登记以及 64 MiB 序列化文件。它不是高吞吐计费仓库，容量、损坏或 I/O 错误不会伪装成零用量。

## 章节审核空间

章节页的生成进度、临时预览与候选稿整合进可整体折叠的审阅工作台。取消固定 180px 卡片上限和页面固定高度，正文阅读区至少 360px；完整正文模式可取消内部滚动，窄屏对比改为上下排列。折叠仅改变显示，不取消后台任务、不改变审核/采用权限，不把候选稿自动当作正式正文。

## 验证

构建后使用隔离脚本：

```sh
node scripts/smoke-token-usage.mjs
node scripts/smoke-generation-review.mjs
```

脚本使用临时部署和合成数据，不连接真实付费模型、个人浏览器或番茄账号。浏览器的模拟统计证明前端交互，不替代后端真实路由的权限与持久化测试。
