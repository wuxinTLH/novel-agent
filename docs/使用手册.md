# Novel Agent

本机单用户小说创作工作台，版本 `1.0.0a`。支持多作品、多工作流、世界观编写、章节创作、资料管理、模型库、主题和本机数据保存。

## 快速开始

需要 Node.js 22.16 及以上版本。

```powershell
npm ci
npm run dev
```

开发界面是 `http://127.0.0.1:5173`，API 是 `http://127.0.0.1:3001`。

生产运行：

```powershell
npm run build
npm start
```

生产界面是 `http://127.0.0.1:3001`。服务只监听本机，不要把端口暴露到公网。

## 使用手册

### 页面

- `/workflow`：创作工作流，可新建、切换、整理和运行节点。
- `/assets`：设定资料，保存世界观、人物、剧情和章节资料。
- `/chapters`：章节书稿，编辑、生成、对比和导出章节。
- `/platforms`：平台连接。番茄真实写入仍需页面验收，不会自动填写正文。
- `/settings`：模型库、协议、密钥和运行模式。

刷新页面会保留当前地址。未知地址显示 404，5 秒后返回上一页；应用错误可从错误页返回首页。

### 世界观编写

1. 在工作流页新建“世界观编写”。
2. 工作流包含开始、自写节点、扩写节点和结束节点。
3. 可填写世界观名称；留空时根据内容生成名称。
4. 运行后只保存世界观正文到设定库。
5. 设定审查、假设标注、章节规划和小说正文不会写入世界观。

世界观流程不创建章节。章节创作应使用独立的章节工作流。

### 章节创作

1. 在模型设置中选择真实模型，或明确使用演示模式。
2. 从工作流或章节页打开“配置目标与要求”。
3. 选择续写、指定单章或章节区间。
4. 保存作品要求或章节要求后运行。
5. 已有章节重生成时只产生候选稿，采用后才替换原稿。

演示模式输出固定模板，不代表模型质量。真实模型调用前必须配置有效地址、模型 ID 和 API Key。

### 模型库

- 可添加多个模型，并在列表中切换当前模型。
- 支持 Chat Completions、Responses API 和 Anthropic Messages。
- 当前模型与运行模式保存在 `data/models.json`，重启后继续使用。
- API Key 加密保存，不返回浏览器，也不写入项目内容。
- 只有模型库为空时才创建初始“默认模型”。已有模型不会在每次启动时被替换成演示模式。

### 界面

- 顶栏可切换浅色、深色、跟随系统和蓝粉白主题，选择会保存在浏览器本地。
- 工作流、章节和表单控件使用统一的 SCSS 样式。
- 窄屏下工作流工具栏自动换行。
- 删除、放弃等操作使用应用内确认框，不使用浏览器原生 alert。

### 节点整理

工作流画布提供四种整理方式：

- 按流程分层
- 横向排列
- 纵向排列
- 网格排列

整理只调整节点位置，不改变节点内容、连线方向或运行结果。

## 数据与安全

复制 `.env.example` 为 `.env` 后按需修改：

```dotenv
PORT=3001
MODEL_BASE_URL=https://api.openai.com/v1
MODEL_NAME=gpt-4.1-mini
MODEL_PROTOCOL=chat-completions
MODEL_API_KEY=your-api-key
```

- `data/` 保存作品、章节、资料和模型配置，不提交到 Git。
- 模型地址不允许指向本机、内网或云元数据地址。
- API 修改请求需要当前进程的 `X-Platform-CSRF`。
- 同一数据目录只允许一个服务实例。
- 平台登录必须由用户在隔离浏览器中完成，应用不会代填正文。

## 验证

```powershell
npm run typecheck
npm test
npm run build
```

`npm test` 使用临时目录和本地测试桩，不会调用真实模型或平台账号。
