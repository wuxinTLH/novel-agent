# 平台能力与 MV3 扩展

语言 / Language：[中文](平台扩展.md) · [English](en/platform-extension.md) · [English documentation index](en/README.md)

## 能力状态

| 平台 / 通道 | 可用能力与接入条件 |
| --- | --- |
| 番茄后端隔离浏览器 | 人工登录、真实身份及作品读取、绑定作品后的草稿保存/全文回读/删除；提交审核另需逐项批准、AI 使用声明与匹配回执。页面或身份不符合预期时失败关闭。 |
| 番茄 MV3 扩展 | 仅单用户、本机 `127.0.0.1:3001` 的双确认配对、能力查询和撤销。`accountVerified/listWorks/saveDraft/submitReview/publishChapter` 始终 false；不把页面打开或配对成功当作账号核验。 |
| 起点、七猫 | unavailable；没有已经核验的官方作者管理 API、应用资质或授权文档。token、OAuth、作品管理、草稿和发布能力全为 false。接入须提供平台许可、应用资质、正式接口/授权及回执规范、最小权限范围和专用测试账号；取得资料之前不猜测接口。 |
| Mock | 仅本地模拟作品管理，不是任何真实平台成功证明。 |

`save_draft` 只保存并回读草稿；`submit_review` 是另一个已批准的动作，成功表示取得送审回执。审核通过、公开可见及正式发布不是它们的同义词。共享能力列表尚无独立 `submitReview` 枚举，因此提供方描述解释送审前提，`publishChapter` 保持 false；扩展 `/capabilities` 则单独返回 `submitReview:false` 及原因。注册表的能力表示后端通道的实现条件，扩展会话的能力始终以 bridge 回报为准。

## 安装扩展

在 Chromium / Chrome / Edge 的扩展管理页开启开发者模式，选择“加载已解压的扩展程序”，选择 [platform-bridge](../extensions/platform-bridge/manifest.json) 所在目录。无需打包或依赖安装。扩展 popup 显示扩展 ID，复制它到配对请求。扩展只访问固定本机服务，不注入番茄网页脚本，不读取 Cookie、不加载远程代码，不存在自动发布、定时任务或后台自动配对。

浏览器的 host_permissions 无法细分端口，因此清单声明 `http://127.0.0.1/*`，但 CSP 的 connect-src 和客户端代码固定 `http://127.0.0.1:3001`。自定义后端端口须同时修改 CSP、客户端 base 和文档后重新加载扩展；不能让网页消息指定服务器地址。`activeTab` 仅在用户打开扩展时授权检查当前标签页，`storage.session` 的 TRUSTED_CONTEXTS 用于保存短期配对凭据，浏览器重启即清除；不保存到 local/sync，不向 popup 返回 token。

认证多租户模式目前返回 `501 EXTENSION_AUTH_MODE_UNSUPPORTED`，包括创建配对。没有实现按扩展来源选择唯一租户 runtime，因此此版本不能在认证模式中使用，也不会通过扩展请求选择普通业务租户。

## 双确认配对

在“平台作品 → 番茄 → 核验账号”的“浏览器扩展配对”卡片输入扩展 ID，生成配对码；在作者后台 popup 批准后回到卡片点“刷新扩展批准状态”，核对来源 ID 与标签页编号、勾选确认并批准，再返回 popup 完成。卡片支持撤销，不持久化配对码。认证模式卡片显示明确不支持原因。

以下是同一流程的开发 API 参考，可在已经打开的本机应用页的浏览器控制台运行；普通使用者使用卡片即可。同源控制台仅调用现有项目作用域和 CSRF 保护的业务接口。切勿把 token、Cookie、配对码或控制台输出发送到外站。

1. 打开 `http://127.0.0.1:3001` 的单用户应用，选定项目。用项目真实 ID 替换下面占位符，用 popup 显示的扩展 ID 替换第二个占位符。获取一次配对码：

```js
const projectId = 'REPLACE_WITH_CURRENT_PROJECT_ID';
const extensionId = 'REPLACE_WITH_32_LETTER_EXTENSION_ID';
const session = await (await fetch('/api/platforms/session')).json();
const headers = { 'Content-Type': 'application/json', 'X-Platform-CSRF': session.csrfToken };
const pairing = await (await fetch(`/api/projects/${encodeURIComponent(projectId)}/platform-extension-pairings`, {
  method: 'POST', headers, body: JSON.stringify({ extensionId }),
})).json();
console.log(pairing);
```

2. 在真正的 `https://fanqienovel.com/main/…` 作者后台标签页打开扩展，粘贴 64 位 challenge，勾选批准，再点击“批准配对”。这只确认当前标签页选择，未核验登录或身份。
3. 返回本机应用控制台，查询配对，核对 `extensionOrigin` 和 `tabId` 是否与 popup 一致；确认前不应仅凭“有请求到达”就继续：

```js
console.log(await (await fetch(`/api/projects/${encodeURIComponent(projectId)}/platform-extension-pairings`)).json());
// 人工核对后明确确认：
await fetch(`/api/projects/${encodeURIComponent(projectId)}/platform-extension-pairings/${pairing.id}/confirm`, {
  method: 'POST', headers, body: '{}',
});
```

4. 回到最初番茄标签页 popup，点击“应用确认后，完成配对”，再点“检查真实能力”。只应显示配对成功与所有平台业务能力不可用。配对码 2 分钟失效；会话最长 30 分钟，不能续期或转移到别的项目/扩展来源。worker 在第一次 finish 前生成并保存 token，同 token 可重试恢复丢失的 finish 响应，不能替换凭据。
5. 点击 popup“断开并清除凭据”。未完成配对或网络中断时，在应用撤销配对：

```js
await fetch(`/api/projects/${encodeURIComponent(projectId)}/platform-extension-pairings/${pairing.id}`, {
  method: 'DELETE', headers,
});
```

服务器重启、项目不存在、会话到期、新配对替换和主动撤销均使旧凭据不可用。claim 响应丢失不能可靠恢复；在应用撤销后重新生成，不盲目重复认领。配对/令牌只在内存或扩展 session storage 中，服务器仅保留其哈希；应用列表不返回 challenge。

## Bridge 协议及边界

基础路径 `/api/platform-extension`，仅允许等待中的指定扩展来源或有效会话对应来源、固定 `Host:127.0.0.1:<应用端口>`，拒绝 Cookie；POST 必须 JSON 且最多 4 KiB，字段严格校验；每个已允许来源每分钟最多 120 次请求。预检只接受 GET/POST/DELETE 和 Authorization/Content-Type，不允许凭据型 CORS。

| 路径 | 请求 |
| --- | --- |
| POST /claim | `{challenge,tabId,approved:true}`；只能认领一次 |
| POST /finish | `{pairingId,claimToken,token}`；两个独立批准完成后绑定项目/来源/标签页 |
| GET /session | `Authorization: Bearer <64位十六进制token>` |
| GET /capabilities | 同上；返回真实 false 能力及每项 unsupported 原因，不能客户端自行上报 true |
| DELETE /session | 同上；撤销会话 |

扩展 worker 仅接受同扩展精确 popup URL 的消息，拒绝网页、content script、其他扩展、额外字段和任意请求地址。无远端写入路径，配对 token 不适用于普通业务 API，不接受远端 Cookie / 平台密码作为 token。

## 验证与剩余限制

安全测试：

```text
node --import tsx --test packages/server/src/features/platforms/extension-bridge.test.ts extensions/platform-bridge/protocol.test.mjs
npm run typecheck
```

覆盖来源/项目/token 绑定、双确认、重复和过期配对、会话撤销、输入有界、Cookie/Host/消息权限拒绝、无发布路由及真实能力回报。使用本机 HTTP 与纯协议验证，不访问真实作者账号。

本轮未提供真实番茄/起点/七猫账号、授权应用材料或发布测试作品，未验收任何真实外部账号读写、送审、公开发布；也未将本地测试当作 Chrome Web Store 审核、线上 DOM 兼容或平台授权证据。需人工加载扩展验证真实 Chrome/Edge 的 Origin、popup 生命周期与配对全流程。番茄后端浏览器历史人工成功记录不代表本轮扩展验证成功。

SQLconnect 的连接测试/保留 schema 与当前 v3 存储激活是不同能力；实时 MySQL / SQL Server 和 v3 PostgreSQL 仍须专用数据库凭据验收。平台锁已由主线程协调跨租户 Worker 和主线程 runtime，保护范围是同一进程；不宣称多实例、跨主机锁或阻止作者手工编辑网站。详见 [SQLconnect](sqlconnect.md) 与 [平台锁实现约定](../packages/server/src/features/platforms/README.md)。
